# bindery

A folder of Markdown becomes a searchable documentation site with live reload.
One binary. Zero dependencies.

## Why

Turning text files into other text files should not require several hundred
packages. `bindery` is one static binary with an empty dependency manifest.

> The registry it pulls from added 454,600 malicious packages last year alone.

Start with the [getting started guide](guide/getting-started.md), or read about
the [edge cases](guide/edge-cases.md) the parser handles.
